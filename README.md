Zomato Data Analysis Using Python

📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on Zomato restaurant data using Python. The main objective is to understand restaurant trends,
customer ratings, votes, online ordering, and dining costs.

🛠️ Tools & Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

📊 Key Analysis

- Analyzed different types of restaurants.
- Explored customer ratings and votes.
- Compared online and offline ordering.
- Studied the approximate cost for two people.
- Created visualizations and a heatmap to understand data patterns.

💡 Key Learnings

- Data cleaning and exploration using Pandas.
- Analyzing restaurant trends and customer preferences.
- Creating visualizations to identify patterns in data.
- Improving practical data analysis skills using Python.

🚀 How to Run

1. Install the required libraries:
   "pip install pandas numpy matplotlib seaborn"
2. Download the dataset and keep the CSV file in the project folder.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Run all cells to explore the analysis.
